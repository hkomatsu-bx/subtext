# Subtext 設計書

Subtext の設計を領域別にまとめた文書群である。
企画書・PoC 実装計画・過去の設計文書群を統合し、これらの後継として置く（統合元は撤去済みで、参照先は本文書群のみ）。

設計・仕様の一次情報は本文書群である。
記述の基線は現行の実装に置き、実装と食い違いが出た場合は本文書群を先に直す（リポジトリルートの `CLAUDE.md` は規約とコマンドを担い、設計の記述は持たない）。
当初 PoC の前提（Python 3.11/3.12、`net8.0-windows` など）から移行した箇所は、該当する節で差分を注記する。

## この文書の読み方

初めて読むなら、概要 → アーキテクチャ → 各ユニット設計の順で読めば全体をたどれる。
特定のトレーサビリティコード（`FR-xx`、`BR-xxx-xx`、`NFR-SEC-xx`、`Qn=A`）の意味を引きたいときは、付録のトレーサビリティを参照する。
これらのコードはソースコードのコメントから参照される識別子であり、その定義は付録が唯一の一次情報になる。
