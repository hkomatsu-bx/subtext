---

## 前処理（必須）

1. **図種別ID**を確定
2. **Scope**を確定
3. **抽象度**（L1/L2）を確定
4. **ノード/エッジ数**を概算（上限：40/60）
5. **グルーピング枠**を先に決める

---

## 共通骨格（この順で作る）

1. **ノード一覧**を確定（状態/画面/コンポーネント/工程…）
2. **グルーピング枠**を先に置く
3. **主要ルートのエッジ**を先に引く（例外は後）
4. **ラベル**を付ける（アクション/条件/データ種）
5. **色・線種・凡例・注記**を最後に固定
6. **整列（グリッド）→交差線削減**

---

## draw.io共通固定ルール

1. **XML形式**で出力
2. **余白確保**: キャンバス上下左右40px以上、重なり禁止
3. **whiteSpace=wrap**: 文字は枠内に収める
4. **グリッド**: 10px、スナップON
5. **サイズ統一**: 同種ノードは同サイズ（目安 W180px/H56px）

### エッジ（矢印）規格（必須）

- **コネクタ**: 直交（orthogonal）で統一
- **線幅**: 1.5pt固定
- **線の色**: 原則グレー固定（線で色分けしない。色はノードで表現）
- **ラベル位置**: 矢印中央（重なる場合は線ではなく配置を直す）
- **Y字分岐禁止**: 分岐は必ずひし形から2本出す（途中枝分かれ禁止）
- **外周配線禁止**: レーン境界に沿った大回りは禁止（ノードを寄せて最短化）
- **交差上限**: 交差が3本超えたら
  ①ノード再配置 → ②合流点追加 → ③分割提案

### 線種ルール

| 線種             | 用途                                  |
| ---------------- | ------------------------------------- |
| 実線（1.5pt）    | 通常フロー                            |
| 点線（dashed=1） | 戻り/ループのみ（例外表現に乱用禁止） |

### 分岐ラベル（Yes/No）配置ルール（必須）

1. ラベルは「ひし形から出る矢印」に付与する（処理ノードから直接Yes/Noは禁止）
2. 基本は矢印中央だが、**線に被る場合は 線から6〜10pxオフセットする**
   - **Yes**：矢印の上側へオフセット
   - **No**：矢印の右側へオフセット
3. それでも被る場合は、**ラベルの置き場を作る**
   - ひし形と接続先ノードの距離を **8〜16px 広げる**（ひし形/接続先どちらを動かしてもよい）
4. **どうしても解消できない場合の最終手段**：
   - 矢印ラベルを削除し、**テキストオブジェクト**で線の近くに配置（背景白推奨）

### UI要件行ルール（トレーサビリティ確保：必須）

**目的**: 「提供したい体験」と「開発」を接続する

| フェーズ   | UI要件の内容（必須項目）                           |
| ---------- | -------------------------------------------------- |
| 認知       | ストアスクリーンショット/動画/CTAの定義            |
| 導入・登録 | ゲスト開始可否、権限提示タイミング、スキップ可否   |
| 初回体験   | 画面遷移数、編集方式（部分/全文）、フォールバック  |
| 達成・報酬 | 完了操作（タップ/スワイプ）、Undo有無、演出頻度    |
| 習慣化     | 通知頻度上限、抑制条件、代替導線（ウィジェット等） |

> **注**: UI要件が空のフェーズがあってはならない

### 感情曲線ルール

- **途中の落ちを1箇所以上入れる**（認識ミス・権限・通知疲れ等）
- 落ち理由は**タグ形式**で控えめに表示（赤文字は避ける）
  - スタイル: `rounded=1;fillColor=#FFEBEE;strokeColor=#FFCDD2;fontSize=7;fontColor=#C62828`
- 感情スコアは**1〜5の全スケール凡例**を右上に配置

- `assets/画面遷移_template.drawio`（画面遷移図。初期/終了状態、戻り遷移＝破線）
- `assets/体制図_template.drawio`（体制図。報告線／承認線／兼務＝破線）

### ファイル命名例

```
[プロジェクト名]_[日本語名]_v{MAJOR}.{MINOR}.drawio
```
